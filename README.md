# AP Computer Science Java

A collection of Java programming exercises, class projects, and course materials from my time in high school in the AP Computer Science course (2015-2016). This is a historical archive of independent assignments, not one application or a single buildable project.

## Contents

- [`code/`](code/) - Java source partially organized into exercises and project folders.
- [`power-points/`](power-points/) - chapter slide decks of related course material (`Ch01.pptx` through `Ch27.pptx`).

The code covers introductory programming and object-oriented topics such as arrays, strings, classes, methods, and simple algorithms. Larger examples include a Chomp game, a fraction class, a lipogram tool, a fortune teller, and a snack bar simulation. Some folders contain supporting images, sound files, or JAR libraries.

## Requirements:

Install a JDK that provides `java`:

1. Download a JDK installer for your operating system.
2. Run the installer and follow its prompts. Enable the option to add Java to `PATH` if available.
3. Open a new terminal and verify the installation:

   ```sh
   java -version
   ```
